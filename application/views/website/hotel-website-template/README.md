# Hotel Website Template

Plain HTML, CSS and JavaScript. No framework or build process.

## Structure

- `index.html` — page structure and editable content
- `css/style.css` — layout, responsive design and styling
- `js/main.js` — booking UI, guest selector, tabs and interactions
- `images/` — put your hotel images here

## Run

Open `index.html` directly, or run:

`python -m http.server 8080`

Then visit `http://localhost:8080`.

## Customization

Replace HOTEL NAME, hero copy, section text, offers, contact details and placeholder backgrounds. Add real images to `images/` and change the `.image-one` / `.image-two` backgrounds in `css/style.css`.

The booking form is frontend-only and ready to connect to a real API/backend.
